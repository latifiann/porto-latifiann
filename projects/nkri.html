NKRI

NKRI merupakan aplikasi komunikasi real-time untuk chat personal dan grup, panggilan suara/video, serta berbagi file.

  • PeranMobile Developer Intern
  • Periode13 Jan–6 Jun 2025
  • Tim6 Orang

Kontribusi

  • Mengembangkan dan menyempurnakan modul komunikasi real-time sebagai salah satu dari dua Mobile Developer dalam tim lintas peran beranggotakan enam orang.
  • Berkontribusi pada reusable UI components, migrasi Socket.IO ke WebSocket, message dispatching, background service integration, reconnect handling, dan user activity status.
  • Mengembangkan prototipe panggilan suara dan video personal berbasis WebRTC, termasuk signaling, offer/answer exchange, ICE candidate handling, media stream, dan call-state management.
  • Mengembangkan message search, filtering, pagination, attachment, media preview, serta alur detail dan pembuatan grup.
