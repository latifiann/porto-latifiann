Mooda App

Mooda merupakan prototipe aplikasi ride-hailing Flutter untuk pemesanan perjalanan oleh pelanggan dan pengemudi dengan pembaruan status secara real-time.

  • PeranMobile Developer Intern
  • Periode21 Jul–5 Des 2025
  • Tim4 Orang
  • ModelRemote · Surabaya

Kontribusi

  • Mengembangkan aplikasi sebagai satu-satunya Mobile Developer dalam tim lintas peran beranggotakan empat orang.
  • Mengembangkan autentikasi, pemesanan dan pembatalan perjalanan, status perjalanan real-time, rating, profil, status pengemudi, serta riwayat perjalanan.
  • Mengintegrasikan REST API melalui Dio, Socket.IO, serta Google Maps untuk pemilihan lokasi, pembaruan lokasi pengemudi, geolokasi, dan reverse geocoding.
  • Menerapkan Riverpod, GoRouter, Hive, arsitektur berlapis berbasis fitur, serta melakukan perancangan UI/UX dan manual testing pada Android.

Teknologi

  • Flutter
  • Dart
  • Riverpod
  • GoRouter
  • Dio
  • Socket.IO
  • Google Maps
  • Hive

Kolaborasi

Prototipe dikembangkan dengan metode hybrid Agile–Waterfall bersama dua Back-End Developer dan satu Front-End Web Developer.
