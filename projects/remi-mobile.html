ReMi · Remind Me

ReMi membantu pengguna mengatur task, menentukan deadline, dan mengelola reminder dalam satu aplikasi. Setiap task yang selesai memberikan koin untuk membeli tema, menghadirkan gamifikasi yang mendorong pengguna lebih konsisten menyelesaikan task.

  • PeranMobile Developer
  • Periode2024
  • Tim8 Orang
  • StatusGoogle Play

Kontribusi

  • Mengembangkan fitur task berbasis BLoC, date picker, optimistic delete undo, validasi input, serta loading dan error state.
  • Mengembangkan dan menyempurnakan Flutter UI untuk halaman profil, autentikasi, welcome, dan alarm, termasuk animasi Lottie.
  • Mengintegrasikan REST API melalui Dio dalam Clean Architecture berbasis fitur, termasuk alur forgot password.
  • Terlibat dalam Design Sprint, Figma, manual testing, bug fixing, dan pembuatan video promosi.

Teknologi

  • Flutter
  • Dart
  • BLoC
  • Dio
  • Clean Architecture
  • REST API
  • Lottie
