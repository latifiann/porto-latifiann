ReMi Web App

ReMi Web App membantu pengguna mengatur task, deadline, dan reminder melalui responsive web app dengan fitur prioritas dan gamifikasi.

Kontribusi

  • Berpartisipasi dalam pengembangan responsive web app bersama tim menggunakan React, TypeScript, Vite, dan Tailwind CSS.
  • Mendukung pengembangan produk dengan lingkup autentikasi, task management, pencarian dan filter deadline, serta reminder berbasis API.
