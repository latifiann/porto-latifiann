Proyek Pembelajaran Mandiri · Back-End Development

Semina

Semina menyediakan REST API untuk mengelola event, pemesanan, dan checkout tiket, lengkap dengan CMS bagi pengelola acara.

  • PeranBack-End Developer
  • PeriodeAgu–Sep 2026
  • ModelProyek Mandiri
  • StatusRepository Publik

Kontribusi

  • Membangun REST API untuk autentikasi peserta, pencarian event, riwayat pesanan, checkout tiket, dan pengelolaan data melalui CMS.
  • Menerapkan JWT terpisah untuk pengguna CMS dan peserta, password hashing dengan bcrypt, role-based authorization, serta organizer-scoped access.
  • Merancang validasi checkout berbasis transaksi MongoDB dengan perhitungan harga dan total pembayaran pada server.
  • Menambahkan email OTP dan konfirmasi checkout, upload gambar JPEG/PNG, serta centralized error handling.

Teknologi

  • MongoDB
  • Mongoose
  • JWT
  • bcrypt
  • Nodemailer
  • Mustache
  • Multer

Status Proyek

Semina dikembangkan lebih lanjut dari materi BuildWithAngga sebagai proyek pembelajaran personal. Proyek belum memiliki public deployment, CI, dan automated test suite.
