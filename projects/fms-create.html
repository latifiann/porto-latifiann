FMS-CREATE

Aplikasi mobile penumpang bus listrik untuk melihat rute, halte, estimasi kedatangan, dan posisi kendaraan secara real-time. Fokus utama proyek ini adalah modular monolith Flutter yang dapat menghasilkan berbagai build variant melalui komposisi modul.

  • PeranMobile Developer
  • PeriodeDes 2025–Jul 2026
  • ModelProyek Akhir Kuliah
  • PlatformFlutter · Android

Kontribusi

  • Mengembangkan aplikasi mobile penumpang secara individu sebagai bagian dari ekosistem FMS lintas platform.
  • Mengintegrasikan autentikasi OTP, session recovery, dashboard, Google Maps, REST API, dan Server-Sent Events.
  • Mengembangkan stream lifecycle management, exponential backoff, secure storage, dan network-aware connection recovery.
  • Melakukan manual dan automated testing untuk memvalidasi fungsi aplikasi serta architecture rules.

Arsitektur Modular Monolith

Struktur aplikasi terdiri dari satu runner module, lima feature module, dan empat core module. Module registration menentukan komposisi fitur saat build dan initialization, sehingga build variant dapat dibuat dengan memasang atau melepas modul sesuai kebutuhan tanpa mengubah fondasi aplikasi.
