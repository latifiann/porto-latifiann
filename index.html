Tentang Saya

Saya merupakan lulusan Sarjana Terapan (D4) Teknik Informatika Politeknik Elektronika Negeri Surabaya. Pengalaman saya mencakup pengembangan aplikasi mobile, web, dan back-end melalui proyek akademik, proyek personal, serta dua program magang industri.

Saya berfokus pada pengembangan antarmuka, integrasi API, komunikasi real-time, pengelolaan data, UI/UX, serta manual dan automated testing. Dalam pengembangan software, saya terbiasa menggunakan Git dan bekerja secara kolaboratif dengan metode Agile.
